- 上游基线：53 个测试文件，1300 项通过、2 项跳过。
- 视频阅读器：58 个测试文件，1292 项通过、2 项跳过；收藏夹专用测试随功能删除，新增画面、模型配置、进程协议、网络解析、prompt 与图片响应测试。

- 用真实 B 站视频读取平台 AI 字幕，再通过安全下载器、FFmpeg 和 MCP 图片格式返回两个指定时间点的原始画面。

本地特殊网络通过显式启用 BILIBILI_MEDIA_DNS=cloudflare 验证；默认仍使用系统 DNS。公网地址校验、Cookie 隔离、下载与输出体积限制、取消和超时处理继续保留。
